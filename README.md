# RED ROOM

디스토피아 지하 아케이드의 3D 가챠 머신에서 오리지널 2D 픽셀 파츠를 추출하고, 생존자를 조립해 8개의 로또 번호를 만드는 플레이 가능한 웹 데모입니다. 한국어/영문 픽셀 폰트와 실제 Three.js 입체 머신을 사용하며, 주요 UI 표면의 모서리는 10px입니다. 캐릭터는 각진 센서 헤드, 기계 섀시, 집게 팔, 길쭉한 다리로 조립한 산업용 로봇입니다. 새 아트 생성에 사용자 레퍼런스나 이전 이미지를 입력하지 않았으며, 기존 의상형 치비 디자인을 사용하지 않습니다.

## 실행

공개 데모: https://leejinho970715-star.github.io/RED_ROOM/

GitHub 저장소: https://github.com/leejinho970715-star/RED_ROOM

`.github/workflows/pages.yml`이 `main` 푸시 시 게임 규칙 테스트를 실행하고 `dist/`를 GitHub Pages에 배포합니다. 게임 파일은 상대 경로로 참조하여 `/RED_ROOM/` 하위 경로에서도 동작합니다. 공유 메타데이터의 대표 URL과 이미지 URL은 공개 GitHub Pages 주소를 사용합니다. 실제 가상화폐 결제·출금·NFT 발행은 연결되지 않은 데모입니다.

파비콘은 빨간 바탕의 픽셀 R 마크로 SVG, 32px PNG, ICO, 180px Apple 터치 아이콘을 제공합니다. `scripts/generate-brand-icons.ps1`로 동일한 아이콘을 재생성할 수 있습니다. Open Graph / X 공유 이미지는 `dist/assets/og-red-room-v1.png`(1734×907)이며, 내장 이미지 생성 도구로 제작한 프롬프트는 `dist/assets/OG-IMAGE-PROMPT.txt`에 보관합니다.

게임 오디오는 최초 클릭/Enter/Space 입력부터 시작됩니다. 오리지널 BGM **BASEMENT SIGNAL**(D minor, 96 BPM, 40초 스테레오 루프)은 `scripts/generate-bgm.mjs`로 합성하며 외부 음원/샘플을 사용하지 않습니다. 하나의 Web Audio 컨텍스트가 버튼 누르기, 추출, 등급별 공개, 장착/해제, 판매, 충전, 리워드 효과음을 재생합니다. `BGM ON/OFF`, `SFX ON/OFF`, 음량을 각각 조절할 수 있으며 설정은 브라우저에 저장됩니다. 숨겨진 탭에서는 음악과 효과음을 일시 정지합니다. 상단 경로와 레드버튼의 기본/추출 상태 문구는 영문입니다. 버튼은 독립 Three.js 캔버스에서 금속 하우징, 둥근 캡, 조명과 누르는 깊이를 렌더링합니다.


## 게임 규칙

레드버튼 표면에는 텍스트가 없으며 외부의 `TAP / CLICK` 안내, 발광, 호버 강조, 키보드 포커스 링과 눌림 깊이로 동작을 안내합니다. 각 추출의 결과 화면에서 등급별 픽셀 폭죽이 재생됩니다. 커먼은 2회 × 24개 스파크, 신화는 14회 × 88개 스파크이며 높은 등급일수록 연출 횟수·입자·시간과 궤적이 증가합니다. 모션 감소 설정에서는 짧은 정적 반짝임으로 대체합니다.

수집함의 전체 선택·전체 판매는 필터/아케이드에서 보이는 카드 수와 관계없이 보유 전체에 적용됩니다. 각 카드에서도 판매 대상을 선택할 수 있으며, 판매 확인 화면은 대상 개수·등급·장착 여부·합계를 보여줍니다. 일괄 판매는 확인한 ID를 한 번에 검증한 후 처리하며, 중복 지급이나 일부만 처리하는 상황을 방지합니다. 이미 등록한 로또 조합은 유지됩니다.

- 레드버튼을 누를 때마다 0.001 DEMO ETH가 차감됩니다.
- 8개 부위: 헤드, 바디, 왼팔, 오른팔, 왼다리, 오른다리, 백팩, 기어.
- 7개 등급 × 8개 부위 = 56개의 고정 파츠 유형. 각 NFT 인스턴스는 별도의 ID와 1–50 번호를 가집니다. 같은 유형도 번호가 다를 수 있습니다.
- 번호별 확률은 2%, 부위별 확률은 12.5%. 번호, 부위, 등급을 별도의 도메인으로 추첨합니다.
- 파츠를 판매하면 제거/장착 해제 후 판매액이 즉시 플레이 잔액에 들어갑니다. 같은 파츠는 두 번 판매할 수 없습니다.
- 초기 데모 파츠 8개와 0.024 DEMO ETH를 제공하며 5개 부위가 처음부터 장착됩니다. 초기 파츠는 추첨 결과가 아닌 명시적인 STARTER입니다.
- 서로 다른 8개 번호를 장착하면 한 라운드에 한 번 로또를 등록할 수 있습니다. 등록 시 조합을 복사해 고정하므로 나중에 파츠를 변경하거나 판매해도 등록 조합은 변하지 않습니다.
- 로또는 1–50에서 중복 없이 8개를 추첨하며 번호 순서는 무관합니다. 데모에서는 등록 직후 결과를 확인합니다. 당첨금은 한 번만 지급되며 라운드를 넘기기 전에 수령해야 합니다.
- 모든 금액은 정수 micro-ETH 단위로 처리하며 플레이 기록은 브라우저 localStorage에 저장됩니다.

| 등급 | 등급 확률 | 1종의 확률 | 판매액 (DEMO ETH) |
|---|---:|---:|---:|
| 신화 | 0.01% | 0.00125% | 0.1000 |
| 에픽 | 0.09% | 0.01125% | 0.0250 |
| 레전더리 | 0.9% | 0.1125% | 0.0050 |
| 유니크 | 4% | 0.5% | 0.0015 |
| 레어 | 10% | 1.25% | 0.0007 |
| 매직 | 25% | 3.125% | 0.0003 |
| 커먼 | 60% | 7.5% | 0.0001 |

1종의 확률은 등급 내 부위 한 종류를 받을 무조건부 확률입니다. 천장 시스템은 없으며 각 추출은 독립적입니다. 로또 보상/판매 가격은 실제 토큰 경제의 수익성이나 준비금을 검증한 값이 아닌 데모 설정입니다.

## 검증 데모의 경계

`crypto.getRandomValues`로 생성한 256비트 시드의 SHA-256 해시를 추첨 전에 공개합니다. 결과를 공개한 후 원본 시드도 공개하며, SHA-256과 rejection sampling으로 번호/부위/등급을 다시 계산합니다. 로또는 부분 Fisher-Yates 방식으로 중복 없는 번호를 생성합니다. 로또 8개 모두 일치할 확률은 `1 / C(50,8) = 1 / 536,878,650`입니다.

**현재 브라우저 데모는 블록체인 서비스가 아닙니다.** 시드는 로컬에 보관되어 브라우저 소유자가 열람/변경할 수 있고, 독립적인 난수 보장이나 조작 방지는 제공하지 않습니다. 체인에 배포된 계약, NFT 민팅, 실제 결제 및 출금은 없습니다. 브라우저 지갑 연결은 계정 주소만 요청하며 서명·송금·체인 변경을 요청하지 않습니다.

공정성 화면에서 시드와 결과를 재검증하거나 JSON을 내려받을 수 있습니다. 저장된 진행 중 추출은 새로고침 시 같은 시드로 마무리하여 비용을 다시 차감하지 않습니다.

## 실제 연동에 제안한 구성 (미확정)

사용자는 아직 네트워크를 선택하지 않았습니다. 권장 검토 구성은 Base, 결제/판매/보상 단위는 네이티브 USDC, 온체인 난수는 Chainlink VRF v2.5입니다. 가스비는 ETH이며 실제 연동은 Base Sepolia에서 먼저 검증해야 합니다. 현재 ETH 데모를 USDC나 Base로 임의로 전환하지 않았습니다.

배포하려면 계약 및 난수 구독 설정, 토큰 주소, 체인 RPC, NFT 메타데이터 저장 위치, 재무 준비금/최대 지급 한도, 스마트 계정 또는 가스 후원 방식 등을 확정해야 합니다. 실제 로또는 공통 마감 시각 전에 조합을 온체인으로 고정하고 마감 후에 VRF 결과를 요청해야 하며, 추첨된 번호를 본 후 티켓을 변경할 수 없어야 합니다.

공식 참조: [Base 수수료](https://docs.base.org/specifications/transactions/network-fees), [Circle 지원 체인](https://developers.circle.com/circle-mint/supported-chains-and-currencies), [Chainlink VRF 지원 체인](https://docs.chain.link/vrf/v2-5/supported-networks).

## 파일

캐릭터와 56종 파츠는 장착 화면·수집함·도감·추출 결과에서 모두 새로운 투명 PNG 픽셀 스프라이트로 표시합니다. 백팩과 기어까지 7개 등급 × 8개 부위를 새로 생성했습니다. 원본 PNG는 변경하지 않고 실제 알파 경계를 기준으로 SVG 표시 영역을 지정해 이웃 조각이 보이지 않게 하며, nearest-neighbor 표시로 도트를 유지합니다. 조작용 레드버튼은 별도의 Three.js 캔버스로 실제 원형 3D 모델을 렌더링하며, 붉은 발광·광택·눌림을 표현합니다. 추출 중에는 버튼을 잠가 중복 결제를 막고, 결과 창을 연 뒤 원형 버튼이 그대로 유지됩니다. 키보드 Enter/Space로도 조작할 수 있습니다.

- `dist/red-button.js`, `dist/red-button.css`: 원형 3D 조작 버튼과 붉은 발광.

- `dist/app.js`: UI, 잔액, 가챠, 판매/장착, 도감, 로또 등록/정산, 지갑 주소 연결.
- `dist/game.js`: 56종 카탈로그, 확률/판매 가격, 추첨 알고리즘, 결과 검증.
- `dist/scene.js`: 지하실, 3D 머신, 실제 머신 버튼 클릭.
- `dist/art.js`: 생성된 2D 일러스트 아틀라스를 부위별 SVG 표시 마스크로 보여주고 캐릭터에 조합합니다. 원본 이미지를 수정하지 않습니다. 캐릭터 좌우 반전을 지원합니다.
- `dist/assets/pixel-robot-parts-v1.png`: 내장 이미지 생성 도구로 참조 이미지 없이 새로 제작한 56종 투명 픽셀 스프라이트.
- `dist/assets/PIXEL-ART-PROMPT.txt`: 새 파츠의 디자인 요구사항과 생성 프롬프트.
- `dist/style.css`, `collection.css`, `polish.css`: 반응형 픽셀 UI와 10px 모서리.
- `tests/game.test.mjs`: 확률 전체 구간, 56종 구성, 판매 정산, 중복 번호 차단, 시드/결과 검증 테스트.

Three.js, Galmuri, Silkscreen의 라이선스를 `dist/assets/`에 포함했습니다.

## Vercel 배포

저장소 루트의 vercel.json에서 framework를 Other(null), outputDirectory를 dist로 고정합니다. 서버용 Node 자동 감지 대신 기존 정적 게임 파일을 배포하고, npm test 통과 후 배포합니다. Vercel Root Directory는 저장소 루트(빈 값)를 사용합니다. main 푸시는 GitHub Pages와 Vercel 자동 배포를 함께 실행합니다.

작은 UI 텍스트는 데스크톱·모바일에서 최소 16px이며, readability.css가 확대된 글씨에 맞춰 카드·메뉴·모달 줄바꿈과 여백을 조정합니다.

메뉴는 GACHA ARCADE / MY NFT PARTS / LOTTERY & REWARDS / FAIRNESS CHECK / SURVIVOR GUIDE 영문으로 표시합니다. navigation.js 및 navigation.css에서 MENU/CLOSE 버튼, PC 메뉴 상태 저장, 모바일 오버레이 메뉴, 바깥 영역·Escape 닫기, 키보드 포커스 이동을 관리합니다.

button-fit.css는 최소 16px 텍스트에 맞춰 주요 버튼의 높이·여백을 조정하고, 카드 자체 너비에 따라 장착/판매 버튼 배치를 전환합니다. 짧은 버튼 라벨은 한 줄로 유지하고, 작은 화면의 긴 모달 문구는 버튼 높이를 늘려 자연스럽게 표시합니다.

## SEOUL STUDIO — 별도 옷입히기 게임

별도 경로 /dress-up/에서 실행하며 기존 로또와 UI, 저장 데이터, 음악을 분리했습니다. 가상의 24세 한국 여성 서윤을 위해 생성한 실사풍 3D 일러스트 복장 18종(데님·오피스·드레스·트렌치·레더·겨울 코트·트위드·린넨·오버롤·프레피·한복 등)을 선택하여 교체합니다. 메시 모델의 360도 회전이 아닌 이미지 기반 게임입니다.

액세서리 4선택, 조명 무드 3종, 랜덤 코디, 5개 상황 미션, 100점 평가, 미션별 최대 3스타, 배지 3종, 9스타 골드 프레임, 최근 12개 룩북, PNG 저장, 확대/드래그가 포함됩니다. 이야기는 서윤의 작은 스타일 스튜디오에서 다섯 장면을 완성하는 내용이며 /dress-up/guide.html과 게임 내 스토리 버튼에서 확인합니다.

BGM Seoul Afterglow는 오리지널 48초/80BPM 스테레오 라운지 음악입니다. scripts/generate-studio-bgm.mjs로 재생성할 수 있고, 첫 사용자 조작 후 재생하며 켜기/끄기·음량·백그라운드 일시정지를 지원합니다. 이미지 생성 도구와 최종 프롬프트는 dist/dress-up/assets/ASSETS.md에 보관했습니다. tests/dress-up.test.mjs에서 미션 점수, 반복 보상 방지, 필수 이미지와 BGM을 검증합니다.

파츠 조합 탭에서 상의·하의·아우터·신발을 독립적으로 변경합니다. 각 3선택으로 81개 조합을 만들고 아우터를 벗을 수 있습니다. parts.js는 부위 카탈로그와 점수(25/25/10/10)를, layers.js는 투명 의상 레이어 합성과 작은 캐시를 관리합니다. 완성 룩 18종은 별도로 유지되며 기존 저장 데이터도 호환됩니다. 파츠 코디는 런웨이·룩북 복원·PNG 저장·랜덤 선택에 연결됩니다. 부위 선택을 빠르게 바꿔도 마지막 선택을 적용하며, 이미지 로딩 실패는 이전 코디를 유지합니다. 파츠 이미지 생성 프롬프트는 dist/dress-up/assets/PARTS-PROMPTS.md에 있습니다.
